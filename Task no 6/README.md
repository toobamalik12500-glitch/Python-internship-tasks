# Task 6 – Student Performance Data Analysis

## Objective
This project is used to analyze student performance using Python and Pandas.

## Features
- Create and display student data
- Calculate average, highest and lowest marks
- Count passing and failing students
- Find the student with highest marks
- Filter students based on marks
- Calculate student grades
- Search student by name
- Find Top 3 students
- Filter students above 80 marks
- Read data from a CSV file
- Save analyzed data to a new CSV file
- Analyze attendance
- Analyze subject-wise performance
- Create basic charts using Matplotlib

## Tools Used
- Python
- Pandas
- Matplotlib

## Files
- `student_data.csv` – Original student data
- `student_analysis.csv` – Analyzed student data
- `.py files` – Main Python program
